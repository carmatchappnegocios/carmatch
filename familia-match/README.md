# La Familia Match — Guía de Diseño Definitiva

## Concepto
La Familia Match es una familia mexicana ficticia que representa a los usuarios de CarMatch. Cada miembro tiene un rol claro, un diseño visual único y una personalidad que conecta con un segmento de audiencia diferente.

**Regla de oro:** TODOS usan la **chaqueta azul oscuro de CarMatch (#0f172a)** como identificador de marca. Esta chaqueta es su "uniforme" — los hace reconocibles al instante.

---

## Paleta de Colores de Marca
| Color | Hex | Uso |
|-------|-----|-----|
| Azul CarMatch | `#0f172a` | Chaquetas, fondo principal |

## Reglas para IA (Generación de Imágenes)

Usa estos prompts para generar imágenes consistentes de cada personaje en herramientas como Midjourney, DALL-E, o Stable Diffusion.

### Prompt base para TODOS:
```
Mexican character, [DESCRIPCION], wearing a dark navy blue jacket with orange CarMatch logo on chest, photorealistic style, warm lighting, friendly expression, [EXTRAS], professional portrait photography
```

### Estilo consistente:
- **Fondo:** Degradado oscuro azul-negro (`#0f172a` a `#1e293b`)
- **Iluminación:** Cálida, golden hour o luz de estudio
- **Formato:** Vertical (9:16) para redes sociales, cuadrado (1:1) para thumbnails
- **Calidad:** Mínimo 1024x1024px
