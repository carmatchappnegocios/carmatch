## Guía Rápida de Uso

### Para crear contenido:
1. **Video rápido (15s):** Un villano + un héroe + escena
2. **Post estático:** Un héroe con app + texto overlay
3. **Story:** Un héroe reaccionando + sticker
4. **Ad de Facebook:** Héroe + auto + CTA

### Colores por personaje:
- Don Match: Azul marino + blanco
- Car-mela: Naranja cálido + crema
- Matchy: Púrpura + negro
- Car-litos: Rojo deportivo + gris
- Villanos: Gris oscuro + rojo/verde (depending on villain)
