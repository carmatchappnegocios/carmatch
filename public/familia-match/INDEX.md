## Elemento Común
Todos usan la **chaqueta azul oscuro (#0f172a)** con el **logo naranja de CarMatch** en el pecho izquierdo.

## Cómo Usar

### Para generar imágenes con IA:
Copia el prompt de cada personaje desde `design.md` y úsalo en:
- Midjourney
- DALL-E
- Stable Diffusion
- Leonardo AI

### Para crear contenido:
1. **TikTok/Reels:** Usa los prompts de "Para videos/redes sociales"
2. **Facebook Ads:** Usa los prompts de "Retrato principal"
3. **Instagram:** Usa los avatares SVG como placeholder

- Don Match: `#0f172a` (chaqueta) + `#FF6B2C` (acento)
