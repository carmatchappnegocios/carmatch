COMO USAR:
----------
1. Abrir el archivo .txt de la categoria que quieras
2. Copiar la seccion PROMPT (esta en ingles, optimizada para Gemini)
3. Pegar en Gemini / Midjourney / DALL-E / Ideogram
4. Generar la imagen
5. Usar la imagen como anuncio de Facebook Ads
6. Copiar el HOOK como texto del anuncio
7. Configurar el CTA como boton del anuncio
8. Usar la SEGMENTACION para configurar el audience en Facebook Ads Manager


CONTENIDO DE CADA ARCHIVO:
---------------------------
- PROMPT: Descripcion en ingles para el generador de imagenes (2-4 oraciones naturales)
  Incluye: personaje de la Familia Match, escena especifica, colores CarMatch, texto overlay, estilo publicitario

- HOOK: Texto en espanol para el copy del anuncio (la pregunta que engancha)

- CTA: Boton del anuncio (ej: "Publica Gratis", "Vende Gratis")

- SEGMENTACION: Sugerencia de audience para Facebook Ads Manager
  - Edad objetivo
  - Ubicacion
  - Intereses

FORMATO DE IMAGEN:
------------------
- Recomendado: 1080x1080 (cuadrado) o 1200x628 (landscape)
- Estilo: Fotografia realista, publicitario, alto contraste
- Texto overlay: Grande y legible en movil
